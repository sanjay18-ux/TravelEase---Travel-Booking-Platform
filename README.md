# TravelEase — Your Journey, One Platform

**TravelEase** is a modern, premium, fully responsive all-in-one travel booking web application designed to help users explore destinations and book various travel services from a single intuitive platform.

---

## 🚀 Key Features

1. **Universal Travel Search Panel**:
   - 8 dynamic categories: **Flights, Trains, Buses, Hotels, Cabs, Car Rentals, Holiday Packages, and Cruises**.
   - Category-specific search inputs, live origin/destination swap affordances, date default pre-fill, and search simulations.

2. **Popular Destinations**:
   - High-resolution visual cards with pricing and guides for **Goa, Manali, Kerala, Jaipur, Kashmir, Bali, Dubai, and Switzerland**.

3. **12 Travel Service Categories**:
   - Flight Tickets, Train Reservations, Bus Tickets, Hotel Reservations, Cab Services, Car and Bike Rentals, Holiday Packages, Cruise Bookings, Adventure Activities, Airport Transfers, Travel Insurance, and Tourist Attractions.

4. **Featured Holiday Packages**:
   - Domestic, International, Family, Honeymoon, and Adventure holiday packages with full inclusions and instant inquiry modals.

5. **Best Travel Deals**:
   - Promotional discount coupons with instant one-click code copy to clipboard.

6. **Interactive Booking & Inquiry Modal**:
   - Interactive modal triggering reservation inquiries with unique generated reference IDs (e.g., `#TE-849204`).

7. **Newsletter Validation**:
   - Client-side email validation with immediate feedback and toast notifications.

8. **Complete Multi-Page Architecture**:
   - `index.html` — Homepage
   - `flights.html` — Flight booking search with stops, airline filters, and flight schedule cards
   - `trains.html` — IRCTC train booking search with classes (1A, 2A, 3A, SL) and quota selection
   - `buses.html` — Intercity Volvo and AC sleeper bus search
   - `hotels.html` — Hotel and resort reservations with star ratings and amenity filters
   - `cabs.html` — Chauffeur cab services and airport transfers
   - `rentals.html` — Self-drive SUV, sedan, and bike rental fleet
   - `packages.html` — Curated holiday vacation packages
   - `cruises.html` — Ocean voyages and island cruise expeditions
   - `destinations.html` — Detailed destination guides with weather, highlights, and budgets
   - `contact.html` — 24/7 help center, contact form, and FAQ accordion
   - `login.html` — Account login page with show/hide password toggle
   - `signup.html` — Free account registration page

---

## 🛠️ Technology Stack

- **HTML5**: Clean, semantic markup.
- **CSS3**: Pure CSS with CSS Grid, Flexbox, custom CSS variables, and zero external CSS frameworks.
- **Vanilla JavaScript**: ES6+ modules and event-driven interaction without any frontend frameworks.

---

## 📱 Responsive Design

- Desktop baseline (1240px container).
- Tablet & iPad adaptations.
- Mobile drawer navigation menu with touch-friendly targets (≥ 44px) and smooth overlay transitions.
